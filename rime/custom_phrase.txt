# custom_phrase.txt — 朙月拼音自定义短语（海宁吴语修订方案）
# 放到 Rime 用户文件夹（Windows：%APPDATA%\Rime）。
# 上游 luna_pinyin.schema.yaml 默认已启用 table_translator@custom_phrase，
# 因此不需要改 luna_pinyin.custom.yaml，也不需要新建任何词库。
#
# 格式：文字<TAB>拼音码<TAB>权重
# 「个」在海宁吴语中作结构助词（约相当于普通话「的」），多单字出现、使用极频繁。
# 「蹔」原词库只收 zhan（台湾《国语辞典》口语音，另记读书音 zan）；
# 大陆《汉语大字典》无 zhan 音，只记 zàn，故此处补 zan，
# 使第 4 类修订（疾進義）的单字能按大陆读音直接打出。
# 只补单字候选，不造词组、不改词库、不影响其他音节与整词候选。
# 想更靠前就把 1000 调大；想恢复默认就删掉对应行。
# 若本文件夹已有 custom_phrase.txt，把末尾几行追加进去即可，不要覆盖。
个	ge	1000
蹔	zan	1000
