# 与上游的详细差异

上游：[TerryTian-tech/OpenCC-...Chinese-government-standards](https://github.com/TerryTian-tech/OpenCC-Traditional-Chinese-characters-according-to-Chinese-government-standards)
（`main` 分支浅克隆，`t2gov/` 目录）。本仓库**不修改上游文件**，全部差异由
`tools/build.py` 从上游重新生成，可复现、可审计。

## 1. 字表（`opencc/*Characters.txt`、`GovVariants.txt`）

共删除 16 条、修改 26 条、新增 13 条。

| 字表 | 操作 | 条目 | 理由 |
| --- | --- | --- | --- |
| `TGCharacters.txt` | 删 | `个→個`、`併→并`、`喫→吃`、`疘→肛`、`箇→個` | 原因 1/3：分立正字不再归并 |
| `TGCharacters.txt` | 改 | `倂→併`、`曏→向`、`閤→閤` | 异体归正；「閤」独立正字 |
| `TGCharacters.txt` | 增 | `纔→才`、`嚮→向`、`𬮤→閤`、`衹→只`、`祇→只 祇`、`秖→只`、`霉→黴` | 原因 2 + 閤/𬮤 分立 + 吴语「只」 + 霉/黴 繁简对应 |
| `TGCharacters_keep_simp.txt` | 删 | `併→并`、`喫→吃`、`疘→肛`、`箇→個` | 同上 |
| `TGCharacters_keep_simp.txt` | 改/增 | `倂→併`、`曏→向`、`閤→閤`、`纔→才`、`嚮→向`、`霉→黴` | 同上（不补简体→繁体）；`霉` 供 Rime simplifier 规范候选 |
| `STCharacters.txt` | 改 | `只→只 隻`（上游首选 `衹`）、`向→向`、`才→才`、`合→合`、`霉→黴`（上游 `黴 霉` 一对多） | 吴语「只」相关词不再输出「衹」；原因 2；「合」不再映射「閤」；「霉」只取正字「黴」 |
| `STCharacters.txt` | 增 | `吃→喫`、`𬮤→閤` | 进食义默认「喫」；閤/𬮤 分立 |
| `TSCharacters.txt` | 删 | `疘→肛` | 「疘」为独立正字，简体同形 |
| `TSCharacters.txt` | 改 | `閤→𬮤`、`閧→哄`、`鬨→哄`、`嚮/纔/曏→向/才/向`、`幷/倂/竝→并` | 閤/𬮤 分立 + 异体归简 |
| `TSCharacters.txt` | 增 | `鬨→哄` | 上游把「鬨」视为规范字未收，今按方案对应简体「哄」 |
| `GovVariants.txt` | 删 | `个→個` | 「个」为助词正字 |
| `VSCharacters.txt` | 删 | `併→并`、`喫→吃`、`疘→肛`、`箇→个`、`閤→合 𬮤 阖 阁` | 分立正字不再是「异体字」，v2s 不处理 |
| `VSCharacters.txt` | 改 | `閧→哄` | 异体「閧」对应简体「哄」 |

**附注两字**：`TGCharacters.txt` / `TGCharacters_keep_simp.txt` /
`TSCharacters.txt` / `VSCharacters.txt` 中 `寔→實/实`、`蹔→暫/暂` 一律改为恒等映射，
不参与异体归并；词表不新增任何含这两字的词组。

## 2. 词表

| 词表 | 重写 | 删除 | 说明 |
| --- | --- | --- | --- |
| `TGPhrases.txt` | 1657 条 | — | 逐字位置还原分立正字，把 `纔/嚮` 归入 `才/向`，把「衹」统一改为「只」，把港台「於」规范为「于」（例外保留），把「霉」统一改为「黴」；「隻」保持分立 |
| `STPhrases.txt` | 953 条 | — | 借助 `rules/split_reference.txt`（OpenCC 原版 595 条分立字词条）恢复「並/併/喫/鬨/箇」，把 `纔/嚮` 改为 `才/向`、「衹」改为「只」、`霉` 改为 `黴`；进食义默认「喫」、喧闹义默认「鬨」 |
| `VSPhrases.txt` | — | 9 条 | 删除全部以「閤」为异体的词条 |
| `TSPhrases.txt` | 0 | — | 上游已符合方案（如 `衹得→只得`、`神祇→神祇`），保持不动；仅补一条 `於莵→於莵` 恒等保护 |

用字约定：海宁吴语一般说「只」，故上游词表中 `只X → 衹X` 的 417 条一律改为
`只X → 只X`；`TGCharacters` 系列补 `衹→只`、`祇→只 祇`、`秖→只`，
`STCharacters` 的 `只` 候选去掉「衹」。量词「隻」相关词条一字未动，
「神祇」「祇洹精舍」由上游词表保护，仍保持原形。

**「於 / 于」**：上游 `TGPhrases` 的 765 条含「於」词条中，改写 736 条为「于」，
保留 29 条（28 条例外词 + 1 条上游本已转「于」的「幾近於」）。例外词为姓氏、人名、
地名与感叹词（於乎、於戲、於菟／於莵、於呼哀哉、於穆、於邑等），由 `HNGuard.txt`
恒等保护；单字「於」不设字表映射，保留姓氏用法。
`STPhrases` 的 12 条 `于X→於X`（感叹词、姓氏人名）与 `TSPhrases` 的既有例外词表
一并保留，故 `s2hn` / `hn2s` 方向行为不变。

**「霉 / 黴」**：《规范字与繁体字、异体字对照表》以「霉—黴」为规范字与繁体正字对应，
即「霉」是「黴」的简化字。上游 `t2gov` 采用港台按义项分化的立场，把「霉」当可独立
使用的传承字保留（`TGCharacters` 系列无 `霉` 条目、`STCharacters` 留 `黴 霉` 一对多
候选、「倒霉」恒等）。本修订按《对照表》统一作「黴」：

| 层面 | 改动 |
| --- | --- |
| 字表 | `TGCharacters` / `TGCharacters_keep_simp` 增 `霉→黴`；`STCharacters` 的 `霉→黴 霉` 改为单值 `黴` |
| 词表 | `STPhrases` / `TGPhrases` 的 `倒霉→倒霉` 各改为 `倒黴`；其余 25 条含「霉」词条上游本已转「黴」 |
| 保护表 | `HNGuard` 不放 `霉`：单字恒等会截胡 `發霉` 的词表命中 |
| 繁→简 | 沿用上游 `黴→霉`，行为不变 |

Rime 侧 `essay.txt` 同时收「發霉」「發黴」（词频均 1135）；`TGCharacters_keep_simp.ocd2`
把候选「發霉」规范为「發黴」后，由 schema 自带的 `uniquifier` 去重，
`famei` 只出一个「發黴」候选，单字 `mei` 同理。

新增两个**优先词表**（置于转换链最前，`short_circuit` 命中即返回）：

- `opencc/HNPhrases.txt`（93 条）：`简 → 修订繁` 的方案特例，来自 `rules/overrides.tsv`，
  是协作者最常用的编辑入口。
- `opencc/HNGuard.txt`（46 条）：`繁 → 修订繁` 的保护词条，防止「真个」「个中」「内閤」
  及含「於」的姓氏人名、地名、感叹词被归并。

## 4. 保留上游的部分

- 五种基础方案 + jieba 变体 + keep_simp 变体全部保留（25 个 json）。
- `CJK_Compatibility_Ideographs.txt` 正规化预处理、`normalization` 链保持不变。
- 上游对旧字形、表外异体字、类推简化字的处理，以及 `內→内` 等
  [《通用规范汉字表》](https://www.gov.cn/zhengce/content/2013-08/19/content_1289.htm)新字形规范，**本修订均未改动**。
- 上游 `STCharacters.txt` 其余「古籍整理时保留异体字作为一对多转换」的候选一律保留，
  仅「霉」按《对照表》改为单值「黴」（生成时连带上游注释一并替换）。
- `t2hn` 对「个/個/箇」一律原样保留；如需把繁简混杂稿件按义项统一，
  请改用 `s2hn` 或 `t2hn_keep_simp`。
- 单字「於」不设字表映射（保留姓氏用法）；`v2s`、`t2new` 是字形方案，
  不参与「於 / 于」用字约定。

## 5. 已知取舍

1. **未收录词组按默认正字输出**。`s2hn` 覆盖了 5.3 万条词组，但生造词、专名
   仍可能落到单字表默认（「并」→「并」、「哄」→「哄」、「只」→「只」）。
   发现后请在 `rules/overrides.tsv` 补一条，重新 build + verify。
2. **「并」三分不做默认猜测**。因为「并 / 併 / 並」的选择必须依赖语义，
   只能由词组表决定，不设单字默认值。
3. **「神祇」保留**。方案把「祇」「秖」列为「只」的异体，但「神祇」为固定词，
   上游词表已保护，本修订沿用，避免误改。
4. **`𬮤` 位于 CJK 扩展区**，部分老字体、老输入法无法显示。Rime 词库已收录，
   Web 端请使用支持扩展区的字体（如思源黑体 / Noto Sans CJK 最新版）。
5. **「於」只按词条规范**。未在 `TGPhrases` 收录的生造词、以及单字「於」保持原字形，
   既不误伤姓氏，也避免为单字设全局映射；需要时请在 `tools/rules.py` 的
   `YU_KEEP_PHRASES` / 词条中补充。
6. **「霉 / 黴」按《对照表》作一简对一繁，不按义项分化**。同音归并简化会损失字义信息
   （「霉雨」「倒霉」的「霉」原本并非「黴」的简化），港台正体因此按义项分化保留「霉」；
   本仓库依据《通用规范汉字表》，故一律作「黴」，同时不保留 `黴 霉` 一对多候选。
   如需恢复分化，删 `MEI_ORTHODOX` 相关的 3 条字表补丁与 `tg_value` / `st_value`
   中的 `霉→黴` 分支，重新 build 即可。
